## Kapsam ve API

Yok/auto için sırayla ilk hazır cihaz dili seçilir; eşleşme yoksa tr/fallback. Türkçe daima güvenli geri dönüş dilidir.

Üretimde hazır dil yalnız Türkçedir. İngilizce örnekleri yalnız açık `availableLanguages:['tr','en']` sentetik test girdilerinde kullanılır; gelecekte bu girdinin üretim adaptörü tam çeviri kabulünden sorumlu olacaktır.
